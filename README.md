# GANs for MNIST Digit Generation

## Project Goal

The goal of this project is to implement and compare two different Generative Adversarial Network (GAN) architectures for synthesizing realistic handwritten digits. Using the MNIST dataset, this project explores:
1.  A classic **Vanilla GAN** built with fully-connected layers.
2.  A modern **Deep Convolutional GAN (DCGAN)** built entirely with convolutional layers.

## Approach

The project involves a comparative analysis of two GAN architectures, both trained on the MNIST dataset. The workflow includes performance optimizations and quantitative evaluation.

**1. Data Preparation**
* The standard **MNIST dataset** of handwritten digits was used as the ground truth.
* The images were reshaped to `(28, 28, 1)` and normalized to a range of `[-1, 1]` to match the `tanh` activation function of the generator's output layer.
* The data was loaded into a `tf.data.Dataset` pipeline for efficient, large-batch training, with caching and prefetching enabled.

**2. Model Architectures**

Two distinct GANs were implemented:

* **Vanilla GAN (FCGAN):** This model uses a classic architecture composed entirely of `Dense` (fully-connected) layers.
    * **Generator:** Takes a 100-dimensional latent vector and passes it through several dense layers with `LeakyReLU` activations to produce a flattened 784-pixel output, which is then reshaped into a 28x28 image.
    * **Discriminator:** Flattens the input image and passes it through several dense layers with `Dropout` to classify it as real or fake.

* **Deep Convolutional GAN (DCGAN):** This model follows the architecture proposed in the original DCGAN paper, using convolutional layers for spatial feature learning.
    * **Generator:** Uses a series of `Conv2DTranspose` (deconvolution) layers to upsample a 100-dimensional latent vector into a 28x28 image.
    * **Discriminator:** Uses `Conv2D` layers with strided convolutions to downsample the image and classify it as real or fake.

**3. Training and Optimization**
* **Loss Function:** Both models were trained using **Binary Cross-Entropy** loss. The generator aims to minimize this loss by fooling the discriminator, while the discriminator aims to minimize it by correctly classifying real and fake images.
* **Optimizer:** The **Adam optimizer** was used for both the generator and the discriminator.
* **Performance:** Code was optimized for speed using TensorFlow's `@tf.function(jit_compile=True)` decorator to leverage **XLA (Accelerated Linear Algebra)** compilation and **Mixed Precision Training** (`mixed_float16`) for faster execution on compatible GPUs.

**4. Evaluation**
* **Qualitative:** Images were generated at regular intervals during training to visually monitor the generator's progress.
* **Quantitative:** The **Fréchet Inception Distance (FID)** was calculated to provide a quantitative measure of the quality and diversity of the generated images compared to the real MNIST images. A lower FID score indicates better performance.

## Key Findings and Interpretation

**1. DCGAN Performance**
* **Training Time:** The model was trained for **600 epochs**.
* **Final FID Score:** The DCGAN achieved a **Fréchet Inception Distance (FID) of 40.18**. This is a respectable score indicating that the model learned to generate images that are statistically similar to the real MNIST digits.
* **Generated Images:** The final images produced by the DCGAN are clearly recognizable as digits, demonstrating the effectiveness of the convolutional architecture for image synthesis.

**2. Vanilla GAN (FCGAN) Performance**
* **Training Time:** The model was trained for **500 epochs**.
* **Generated Images:** The images generated by the Vanilla GAN are less sharp and recognizable compared to the DCGAN. While some digit-like structures are formed, they lack the clarity and definition of the DCGAN's output. This highlights the advantage of using convolutional layers for spatial tasks.

**3. Loss Curve Analysis**
As expected for GANs, the loss curves for both models are highly unstable and do not converge smoothly. The generator and discriminator losses fluctuate as they compete against each other. This confirms that loss values are not a reliable indicator of a GAN's image quality, reinforcing the need for metrics like FID.

## Conclusion

This project successfully implemented and compared a Vanilla GAN and a DCGAN for generating handwritten digits. The results clearly demonstrate the superiority of the **DCGAN architecture**, which produced significantly more realistic and higher-quality images, validated by a strong **FID score of 40.18**.

The project confirms that convolutional layers are critical for capturing the spatial hierarchies in image data, leading to better performance in generative tasks compared to models that rely solely on fully-connected layers.
